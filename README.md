# PixelVault Gaming & Service

Sitio estático hecho con HTML y CSS, listo para publicar en GitHub Pages.

## Publicarlo en GitHub Pages
1. Crea un repositorio en GitHub.
2. Sube `index.html` y `style.css` a la raíz del repositorio.
3. Entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, y pulsa **Save**.
6. Espera a que GitHub Pages publique la página. El enlace aparecerá en esa misma sección.

Las imágenes, Google Fonts e iconos se cargan desde servicios externos, así que requieren conexión a internet.
El formulario usa `mailto:`: abre la aplicación de correo del visitante y no guarda solicitudes en una base de datos.
